# 既存 plugin_node 命令との重複・互換性方針

低レイヤー命令（`plugin_lowlevel`）と既存標準cnako 527命令（`plugin_node` / `plugin_system`）の重複をどう扱うかを固定する。機械可読な命令一覧は [`catalog.json`](catalog.json)、型・エラー契約は [`G0_FOUNDATION.md`](G0_FOUNDATION.md) を参照する。

## 原則

- 低レイヤー命令は既存527命令を置き換えない。両方の名前を維持し、`plugin_lowlevel` は新規名前空間として追加する。
- 低レイヤー命令の第一名は既存527命令の表示名と衝突させない（[`check_low_level_spec.mjs`](../../tools/check_low_level_spec.mjs) がCIで衝突を検査する）。
- 同じ操作のうち、全量メモリ読み込みで済む既存APIと、ストリーム/ハンドルで済む低レイヤーAPIは別命令として共存する。呼び出し側は用途で選ぶ。
- cnako互換の観点では、Node標準APIで表現できる低レイヤー命令を `portable_core` / `posix_extension` として定義し、既存527命令の公式契約を変更しない。

## 重複と使い分け

| 既存命令 | 低レイヤー命令 | 使い分け |
| --- | --- | --- |
| `開` / `読` | `ファイル開く` + `ファイルバイト読む` | 既存は全量読み込みのlossy UTF-8 String。低レイヤーはハンドル経由のchunked Bytes |
| `バイナリ読` | `ファイル開く` + `ファイルバイト読む` | 既存は全量Bytes。低レイヤーは一定メモリの逐次読み込み |
| `保存` | `ファイル開く` + `ファイルバイト書く` | 既存は全量書き込み。低レイヤーはハンドル経由の逐次書き込み |
| `ファイル情報取得` | `ファイル詳細情報取得` | 既存はNode `fs.Stats` 互換の辞書（ミリ秒Number）。低レイヤーはナノ秒BigIntを正本にした詳細辞書。既存の互換契約は変更しない |
| `ファイルサイズ取得` | `ファイル詳細情報取得` | 既存はサイズのみNumber。低レイヤーは詳細辞書から取得 |
| `ファイル列挙` / `全ファイル列挙` | `ディレクトリ開く` + `ディレクトリ次取得` | 既存は配列を返す一括列挙。低レイヤーは数百万件でも一定メモリの逐次列挙 |
| `ハッシュ値計算` | `ハッシュ開始` + `ハッシュ追加` + `ハッシュ完了` | 既存はone-shot。低レイヤーはincremental。アルゴリズム名の正規化は既存をsource of truthとする |
| `起動` / `コマンド実行` | `プロセス起動` | 既存はshell command string。低レイヤーはargv境界を保持しshell再解釈しない |
| `システム関数存在` | `低レイヤー機能対応判定` | 既存はカタログ名の存在。低レイヤーはsemanticなcapability。両方trueになり得る |

## 同名解決

- `plugin_lowlevel` は `plugin_node` / `plugin_system` の同名解決を壊さない。低レイヤー命令の名前は527件と衝突しないため、既存の解決優先順位に影響しない。
- 既存の `ファイル名抽出` / `パス抽出` など、同じ名前を複数pluginが持つ31組の解決契約は変更しない。
- AOTの命令dispatch（`aot_builtin`）とInterpreterのplugin chainへ `plugin_lowlevel` を追加するときは、既存ルートより後に検索するか、名前衝突がないこと（本カタログが保証）に依存する。

## 型の互換

- 低レイヤー命令が返す `handle` は既存527命令の戻り値型と混在しない。handleはハンドル表に載る不透明オブジェクトであり、`ファイル情報取得` の辞書やNumberではない。
- `ファイル詳細情報取得` の時刻はナノ秒BigIntを正本にし、既存 `ファイル情報取得` のミリ秒Numberの互換契約は維持する。両者は同じOS値を異なる精度で返す。

## 検証

- 既存527命令のoracle（`compare_native_oracle.mjs` 等）は変更しない。
- 低レイヤー命令の追加・改名は [`check_low_level_spec.mjs`](../../tools/check_low_level_spec.mjs) が527件衝突とcapability整合をCIで検証する。
- 低レイヤー命令が既存命令と同じ名前を使った場合はCIが失敗するため、意図的なオーバーライドは契約上発生しない。
