# lnako v0.2.6 リリースノート

日本語プログラミング言語なでしこ3のネイティブコンパイラ `lnako` バージョン **v0.2.6** のリリースです。
簡易HTTPサーバのセキュリティ修正を中心とするパッチリリースです。辞書リテラルの数値要素と基数リテラルの互換性も改善しました。

## 主な変更点（v0.2.5からの改善）

### 1. セキュリティ修正

- **インタープリターの静的配信でリクエスト処理を継続**
  - 静的ファイルの解決や読み込みで発生したI/Oエラーがイベントループに伝わり、1件のリクエストでプロセスが終了することがありました。ファイルの不存在や種別違いは404、読み込み上限の超過は413、権限エラーなどは500でそのリクエストに応答し、後続の処理を継続します。不正なパーセントエンコードを含む静的パスには400を返します。AOT側の静的配信も同じステータス分類にそろえました（[#293](https://github.com/soramikan/lnako/pull/293)、[#219](https://github.com/soramikan/lnako/pull/219) の残件）。

- **AOT簡易HTTPサーバの保留接続数に上限を設定**
  - AOTでは応答を保留した接続が蓄積し、ファイルディスクリプタが枯渇すると新しい接続を受け付けられなくなるおそれがありました。保留接続を最大16件に制限し、上限に達している場合は最も古い保留接続を閉じてから新しい接続を保留します（[#294](https://github.com/soramikan/lnako/pull/294)、[#220](https://github.com/soramikan/lnako/pull/220) の残件）。

- **AOT静的配信で配信ルート外のファイル読み出しを防止**
  - `realpath` で配信ルート（docroot）内にあることを確認してからファイルを開くまでの間に、ディレクトリ階層が書き換わることでdocroot外のファイルが読み出される競合（TOCTOU）がありました。開いたdocrootのディレクトリハンドルを起点にパスを1段ずつたどり、開いたファイルから読み込む方式に変更しました。配信対象へのパスではシンボリックリンクをたどらず、POSIXではファイルの同一性も検証します。差し替え競合の回帰テストはLinuxを対象としています（[#296](https://github.com/soramikan/lnako/pull/296)、[#219](https://github.com/soramikan/lnako/pull/219) の分割候補）。

### 2. 公式処理系との互換性修正

- **辞書リテラルの数値だけの要素を受理**
  - 公式 `cnako3` v3.7.24と同じく、`｛10｝` をキー `"10"`、値 `10` の辞書として扱います。数値は文字列キーに正規化され、たとえば `｛1e3｝` のキーは `"1000"` になります。複数の数値要素を並べたり、明示キーと混在させたりできます。キーが重複した場合は後の要素を採用します。先頭や連続したコンマは構文エラーになりますが、末尾コンマは使用できます（[Issue #292](https://github.com/soramikan/lnako/issues/292)、[#295](https://github.com/soramikan/lnako/pull/295)）。

- **基数リテラルの丸めと変換を修正**
  - 符号なし64ビット整数の範囲を超える2進・8進・16進リテラルを公式と同じbinary64の値に丸めます。先頭のゼロを除いた有効桁数だけで桁あふれが確定する場合は、多倍長整数への変換を省略して `Infinity` を返します。境界の値は正確に丸め、不正な桁や区切りの診断は従来どおり行います（[#295](https://github.com/soramikan/lnako/pull/295)）。

### 3. 内部変更

- 辞書リテラルの差分テスト追加に合わせ、互換性の検証データと命令ディスパッチのカバレッジ正本を再生成しました。CIと文書検査で照合する件数も更新しました（[#295](https://github.com/soramikan/lnako/pull/295)）。

## インストール

### macOSでHomebrewを使う

Homebrewでv0.2.6の配布が開始された後、次のコマンドでインストールできます。インストール済みの場合は `brew update && brew upgrade lnako` で更新します。

```sh
brew tap soramikan/tap
brew install lnako
lnako --version
```

### ファイルをダウンロードして使う

以下のファイル名はリリースワークフローの命名規則に基づきます。

- **standard** はプログラムの実行と構文チェックに使える軽量版です。ネイティブ実行ファイルを作成するには `lnako toolchain install` でLLVM/LLDを追加します。
- **full** はLLVM/LLDを同梱しています。

| OS・CPU | standard | full（LLVM/LLD同梱） |
| --- | --- | --- |
| macOS・Apple Silicon（arm64） | `lnako-0.2.6-macos-arm64.tar.gz` | `lnako-0.2.6-macos-arm64-full.tar.gz` |
| Linux・x86_64（GNU） | `lnako-0.2.6-linux-x64.tar.gz` | `lnako-0.2.6-linux-x64-full.tar.gz` |
| Windows・x86_64（MSVC） | `lnako-0.2.6-windows-x64.zip` | `lnako-0.2.6-windows-x64-full.zip` |

展開後はフォルダー構成を保ったまま、`bin` フォルダーをPATHに追加してください。AOTでビルド済みのサーバに修正を適用するには、v0.2.6でビルドし直し、再デプロイしてください。

## はじめての実行

UTF-8で `hello.nako3` を作成します。

```nako3
「こんにちは、世界！」と表示する。
```

```sh
lnako check hello.nako3
lnako run hello.nako3
```

ネイティブ実行ファイルを作成する場合は `lnako build hello.nako3 -o hello -O2` を実行します。standard版やHomebrew版では初回に `lnako toolchain install` を実行してください。Windowsでは出力名に `hello.exe` を指定します。詳しくは [使い始める](https://github.com/soramikan/lnako/blob/e795675bac7c899e6f3d53d2ef18d6caba10f84e/docs/GETTING_STARTED.md) をご覧ください。

## その他の添付ファイル

- `*.sha256` と `SHA256SUMS` で、ダウンロードした配布ファイルのチェックサムを確認できます。
- `*.spdx.json` は同梱ソフトウェアの構成情報（SBOM）です。
- `Source code (zip / tar.gz)` はソースからビルドする開発者向けです。
