# lnako v0.2.2 リリースノート

日本語プログラミング言語なでしこ3のネイティブコンパイラ `lnako` バージョン **v0.2.2** のリリースです。
本バージョンは、公式なでしこ3との言語互換性・構文診断の大幅強化、パッケージマネージャー（`lnako pkg`）の取得・キャッシュ・実体化・環境同期パイプラインの実装、OS低レイヤーAPI群（ファイル時刻、逐次ディレクトリ列挙、POSIX権限、argvプロセス、TTY、ロケール比較・表示幅）の拡充、および実行時メモリ安全性・例外ハンドラ残留の修正を含む大型アップデートです。

## 主な変更点（v0.2.1からの改善）

### 1. なでしこ3言語構文・セマンティクスと公式互換性の大幅向上

- **「それ」の伝播・ローカルスコープ・復元の公式互換化**：
  - 関数呼び出し時に関数ローカルな「それ」スコープを分離し、外側スコープへの不要な副作用を防止しました（[#116](https://github.com/soramikan/lnako/issues/116), [#150](https://github.com/soramikan/lnako/pull/150)）。
  - 助詞呼び出し時の省略引数を「それ」で自動補完するように改善しました（[#105](https://github.com/soramikan/lnako/issues/105), [#106](https://github.com/soramikan/lnako/pull/106)）。
  - 連文における「それ」の伝播と戻り値無し関数の連鎖挙動を公式処理系と一致させました（[#114](https://github.com/soramikan/lnako/issues/114), [#162](https://github.com/soramikan/lnako/pull/162)）。
  - 「反復」や「〜の間」などのループにおいて、要素束縛・「それ」束縛およびシステム変数（「回数」「対象」等）の退避・復元を公式準拠にしました（[#112](https://github.com/soramikan/lnako/issues/112), [#149](https://github.com/soramikan/lnako/pull/149), [#113](https://github.com/soramikan/lnako/issues/113), [#154](https://github.com/soramikan/lnako/pull/154)）。
  - 「それ」の復元失敗時にエラーを黙殺せず正しく報告するように改善しました（[#180](https://github.com/soramikan/lnako/pull/180)）。

- **構文解析・字句解析・文法受理規則の拡充**：
  - 制御構文の引数を助詞で照合し、引数の記述順序に依存しない解釈を実現しました（[#118](https://github.com/soramikan/lnako/issues/118), [#158](https://github.com/soramikan/lnako/pull/158)）。
  - 単文の「もし〜ならば」に次行の「違えば」を正しく接続できるようにしました（[#138](https://github.com/soramikan/lnako/pull/138), [#137](https://github.com/soramikan/lnako/pull/137)）。
  - 「AがBならば」形式の条件式を助詞呼び出しとして正しく受理するようにしました（[#132](https://github.com/soramikan/lnako/pull/132)）。
  - 初期値省略の変数・定数宣言および公開属性を受理するようにしました（[#122](https://github.com/soramikan/lnako/issues/122), [#135](https://github.com/soramikan/lnako/pull/135)）。
  - 「〜こと」語尾による関数呼び出し構文（[#116](https://github.com/soramikan/lnako/issues/116), [#150](https://github.com/soramikan/lnako/pull/150)）および「{関数}名」による関数参照構文（[#124](https://github.com/soramikan/lnako/issues/124), [#145](https://github.com/soramikan/lnako/pull/145)）に対応しました。
  - 関数内で実引数配列へアクセスできる暗黙のシステム変数『引数』を導入しました（[#123](https://github.com/soramikan/lnako/issues/123), [#136](https://github.com/soramikan/lnako/pull/136)）。
  - 助詞付き命令呼び出し直後の『戻る』が呼び出し結果を返す挙動に対応しました（[#151](https://github.com/soramikan/lnako/pull/151)）。
  - 値位置・連鎖位置に置かれた組み込み命令語を暗黙の呼び出しとして解決するようにしました（[#111](https://github.com/soramikan/lnako/issues/111), [#153](https://github.com/soramikan/lnako/pull/153)）。
  - 範囲オブジェクト（`A〜B`）の反復、および「N回」繰り返しの非数値オペランドの公式互換数値化に対応しました（[#117](https://github.com/soramikan/lnako/issues/117), [#157](https://github.com/soramikan/lnako/pull/157), [#165](https://github.com/soramikan/lnako/issues/165), [#174](https://github.com/soramikan/lnako/pull/174)）。
  - 「定める」が『と』助詞を値として受理し、定義対象を変数名に限定する検証を追加しました（[#115](https://github.com/soramikan/lnako/pull/115)）。
  - 「。。。」をブロック終端（『ここまで』相当）として字句解析できるようにしました（[#121](https://github.com/soramikan/lnako/issues/121), [#133](https://github.com/soramikan/lnako/pull/133)）。
  - 関数値呼び出しの多段『(』連鎖、区切り式内での助詞呼び出し、助詞付きcall_value直後の『[』の受理規則を公式互換にしました（[#128](https://github.com/soramikan/lnako/issues/128), [#160](https://github.com/soramikan/lnako/pull/160), [#143](https://github.com/soramikan/lnako/pull/143), [#163](https://github.com/soramikan/lnako/issues/163), [#171](https://github.com/soramikan/lnako/pull/171)）。

- **コンパイル時診断・エラー検出の強化**：
  - ループ構造の外側に書かれた『抜ける』『続ける』をコンパイル時エラーとして診断するようにしました（[#166](https://github.com/soramikan/lnako/issues/166), [#173](https://github.com/soramikan/lnako/pull/173)）。
  - 助詞が宣言と一致しない引数を位置引数として誤受理せず、公式同様に『未解決の単語』として診断するようにしました（[#108](https://github.com/soramikan/lnako/issues/108), [#161](https://github.com/soramikan/lnako/pull/161)）。
  - 裸の式文に対して『不完全な文です』の構文エラーを報告するようにしました（[#125](https://github.com/soramikan/lnako/issues/125), [#156](https://github.com/soramikan/lnako/pull/156)）。
  - 関数名（組み込み命令名）への代入をコンパイル時に拒否するようにしました（[#126](https://github.com/soramikan/lnako/issues/126), [#141](https://github.com/soramikan/lnako/pull/141)）。
  - 「!厳しくチェック」指定時の未定義変数参照を、公式互換の警告（Warning）として出力するように調整しました（[#127](https://github.com/soramikan/lnako/issues/127), [#144](https://github.com/soramikan/lnako/pull/144)）。
  - 取り込み展開後の合成AST深さの上限超過をコンパイル時に検知・拒否するようにしました（[#109](https://github.com/soramikan/lnako/issues/109), [#159](https://github.com/soramikan/lnako/pull/159)）。

- **ランタイム安定性とメモリ安全性の強化**：
  - エラー監視領域から脱出する経路で `try_end` をemitし、Interpreterの例外ハンドラが残留する問題を解消しました（[#164](https://github.com/soramikan/lnako/issues/164), [#172](https://github.com/soramikan/lnako/pull/172)）。
  - Interpreterの動的IR（Dynamic IR）の所有権管理を正し、リソース解放漏れを防ぎました（[#177](https://github.com/soramikan/lnako/pull/177)）。
  - 「束」（Promise.all相当）のエラー発生経路において、Promise併合状態の解放済み参照（Use-After-Free）を防止しました（[#179](https://github.com/soramikan/lnako/pull/179)）。

### 2. なでしこ3パッケージマネージャー基盤の拡充（`lnako pkg`）

- **パッケージライフサイクルの完全パイプライン**：
  - パッケージキャッシュ管理、チェックサム検証済み実体化、依存同期（`sync`）、環境復旧（`restore`）のパイプラインを実装しました（[#48](https://github.com/soramikan/lnako/issues/48), [#152](https://github.com/soramikan/lnako/pull/152)）。
- **多彩な取得provider**：
  - ローカルpath、Gitリポジトリ、URL（アーカイブダウンロード）、静的HTTPレジストリからのパッケージ取得プロバイダーを実装しました（[#47](https://github.com/soramikan/lnako/issues/47), [#146](https://github.com/soramikan/lnako/pull/146), [#148](https://github.com/soramikan/lnako/pull/148)）。
- **パッケージアーカイブ形式（`.npkg`）**：
  - なでしこパッケージアーカイブ形式 `.npkg` の生成・検証、メタデータ抽出、収録ファイルハッシュ一覧管理を実装しました（[#142](https://github.com/soramikan/lnako/pull/142)）。
- **ロックファイル（`nako.lock`）の高度な制御**：
  - 複数profile集約、既存バージョン優先、部分更新、理由付き差分説明、ロック鮮度判定をサポートしました（[#46](https://github.com/soramikan/lnako/issues/46), [#102](https://github.com/soramikan/lnako/pull/102)）。

### 3. 低レイヤーAPI群（OS/システム機能）の追加

- **ファイルシステム高精度API**：
  - ファイル時刻（アクセス日時/更新日時/作成日時）取得・変更、ファイル切り詰め（`truncate`）、高精度メタデータ操作を追加しました（[#31](https://github.com/soramikan/lnako/issues/31), [#100](https://github.com/soramikan/lnako/pull/100)）。
  - ディレクトリエントリをメモリ消費を抑えてストリーミング取得できる逐次ディレクトリ列挙APIを追加しました（[#33](https://github.com/soramikan/lnako/issues/33), [#101](https://github.com/soramikan/lnako/pull/101)）。
  - POSIXファイルパーミッション、所有者・グループ（UID/GID）、アクセス権限判定（`access`）APIを追加しました（[#34](https://github.com/soramikan/lnako/issues/34), [#99](https://github.com/soramikan/lnako/pull/99)）。
- **プロセス制御・シグナル・端末API**：
  - 引数配列（argv）による安全なプロセス起動、シグナル送信、プロセス優先度（nice値）の取得・変更、TTY端末属性の取得・設定APIを追加しました（[#35](https://github.com/soramikan/lnako/issues/35), [#103](https://github.com/soramikan/lnako/pull/103)）。
- **国際化・端末表示API**：
  - ロケールを考慮したUnicode文字列の比較・照合（Collation）API、および全角・半角やUnicode結合文字を考慮した端末表示幅（Width）計算APIを追加しました（[#38](https://github.com/soramikan/lnako/issues/38), [#178](https://github.com/soramikan/lnako/pull/178)）。
- **基盤アーキテクチャの整理**：
  - 低レベルAPI基盤（プラグイン・AOT・共通基盤）のドメイン分割とリファクタリングを実施し、保守性と拡張性を大幅に向上させました（[#96](https://github.com/soramikan/lnako/issues/96), [#98](https://github.com/soramikan/lnako/pull/98)）。

### 4. CI/CD・開発基盤の最適化

- **CI高速化・安定化（改善計画2）**：
  - キャッシュ識別子（cache identity）の分離、メトリクス計測基盤、並行実行worker=2最適化、AOTコンパイラ成果物の共有化を導入しました（[#104](https://github.com/soramikan/lnako/pull/104)）。
- **開発運用ツールの改善**：
  - pre-pushフックでの非コード変更時スキップ判定をコンパイラ・テストパス基準に改善しました。
  - GitHub Issue/PRテンプレートおよびコミットメッセージ指針を導入しました。

## インストール

### macOS：Homebrewでインストール（推奨）

```sh
brew tap soramikan/tap
brew install lnako
lnako --version
```

インストール後、`lnako run` ですぐにプログラムを実行できます。ネイティブ実行ファイルを作る場合は、初回に `lnako toolchain install` を実行してください。

### ファイルをダウンロードして使う

お使いのOS・CPUに合うファイルを、次の表からダウンロードしてください。

- **standard**：プログラムの実行・構文チェックを始めたい方向けの軽量版です。後から `lnako toolchain install` でコンパイルに必要なLLVM/LLDを追加できます。
- **full**：LLVM/LLDを同梱しています。追加のダウンロードなしですぐにネイティブ実行ファイルの作成を行いたい方はこちらを選んでください。

| OS・CPU | standard | full（LLVM/LLD同梱） |
| --- | --- | --- |
| macOS・Apple Silicon（arm64） | [lnako-0.2.2-macos-arm64.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.2.2/lnako-0.2.2-macos-arm64.tar.gz) | [lnako-0.2.2-macos-arm64-full.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.2.2/lnako-0.2.2-macos-arm64-full.tar.gz) |
| Linux・x86_64（GNU） | [lnako-0.2.2-linux-x64.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.2.2/lnako-0.2.2-linux-x64.tar.gz) | [lnako-0.2.2-linux-x64-full.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.2.2/lnako-0.2.2-linux-x64-full.tar.gz) |
| Windows・x86_64 | [lnako-0.2.2-windows-x64.zip](https://github.com/soramikan/lnako/releases/download/v0.2.2/lnako-0.2.2-windows-x64.zip) | [lnako-0.2.2-windows-x64-full.zip](https://github.com/soramikan/lnako/releases/download/v0.2.2/lnako-0.2.2-windows-x64-full.zip) |

展開後はフォルダー構成を保ったまま、`bin` フォルダーをPATHに追加してください。macOS版はDeveloper IDによるコード署名・Appleの公証に対応しています。

## はじめての実行

UTF-8で `hello.nako3` を作成します。

```nako3
「こんにちは、世界！」と表示する。
```

```sh
lnako check hello.nako3          # 構文・意味チェック
lnako run hello.nako3            # スクリプトとして直接実行
```

ネイティブ実行ファイルを作る場合：

```sh
# standard版・Homebrewでは初回のみ必要（full版では不要）
lnako toolchain install
lnako build hello.nako3 -o hello -O2
./hello
```

Windowsでは出力名を `hello.exe` にして、`.\hello.exe` で実行してください。詳しい導入手順は[使い始める](../GETTING_STARTED.md)をご覧ください。

## その他の添付ファイル

通常のインストールでは、上の表のアーカイブだけで始められます。

- `*.sha256` / `SHA256SUMS`：ダウンロードしたファイルのチェックサム確認用。
- `*.spdx.json`：同梱ソフトウェアの構成情報（SBOM）。
- `benchmark-*.md` / `benchmark-*.json`：各OSのベンチマーク結果。
- `Source code (zip / tar.gz)`：ソースからビルドする開発者向け。
