# lnako v0.2.1 リリースノート

日本語プログラミング言語なでしこ3のネイティブコンパイラ `lnako` バージョン **v0.2.1** のリリースです。
本バージョンは、HTTPS通信時のパニック解消、UTF-8 BOM付きソースコードの実行対応、インデント構文におけるエラー監視構文解析の修正、およびCI/CDパイプラインの高速化・安定化を含むバグ修正リリースです。

## 主な変更点（v0.2.0からの改善）

### 1. HTTPS通信およびHTTPリダイレクト時の安定性向上
- **TLS接続前の初期化漏れによるパニックの解消**：
  - `HTTPデータ取得` などの命令でHTTPS接続を行う際、TLS文脈（`client.now` やCA証明書バンドル）の初期化前にTCP接続を開始していたため、panic（exit 134）が発生していた問題を修正しました（[#82](https://github.com/soramikan/lnako/issues/82), [#97](https://github.com/soramikan/lnako/pull/97)）。
- **HTTPからHTTPSへのリダイレクト対応**：
  - 初回接続がHTTPであっても、リダイレクト先がHTTPSである場合に備えて事前にTLS文脈を初期化し、InterpreterおよびAOTコンパイル実行の両経路で安全に通信できるようにしました。
- **構造化エラーハンドリング**：
  - TLS初期化失敗時にクラッシュするのではなく、`AJAX失敗時` や `エラー監視` で捕捉可能な通常のエラーとして報告されるように改善しました。

### 2. UTF-8 BOM付きソースコードの実行対応
- **先頭BOMの自動読み飛ばし**：
  - Windowsのメモ帳などで保存されたUTF-8（BOM付き）ファイルの先頭BOM（`U+FEFF`）を自動的に読み飛ばし、そのまま実行および構文検査を行えるようにしました（[#83](https://github.com/soramikan/lnako/issues/83), [#94](https://github.com/soramikan/lnako/pull/94)）。
- **診断位置と文字列テンプレートの境界維持**：
  - ソースマップおよびエラー診断の行・列番号がBOM直後の本文先頭に正しく一致するよう調整しました。
  - 文字列テンプレート展開式の断片など、ファイル先頭以外の位置に存在する文字は誤って除去されないよう境界を維持しています。

### 3. インデント構文における『エラーならば』の構文解析修正
- **エラー監視ブロックの早期終了を修正**：
  - インラインインデントおよび明示インデント構文において、ブロック内の行頭に『エラーならば』を記述した際、直前に余分な『ここまで』が挿入されて『エラー監視』が早期に閉じられてしまう不具合を修正しました（[#81](https://github.com/soramikan/lnako/issues/81), [#95](https://github.com/soramikan/lnako/pull/95)）。
  - 『違えば』と同様に親ブロックの字下げレベルを正しく維持し、公式なでしこ3と同一の挙動を実現しました。

### 4. CI/CDパイプラインの高速化とAttestation移行
- **GitHub Attestationsへの直接移行**：
  - 互換性証拠の検証を公式のGitHub Attestations（`gh attestation verify`）へ直接移行しました（[#87](https://github.com/soramikan/lnako/pull/87)）。
- **CIの高速化と平準化**：
  - 変更内容に基づく選択的軽量CI（Stage 2）の導入（[#89](https://github.com/soramikan/lnako/pull/89)）、Windows native AOTコンパイラの並行ビルド共有（[#92](https://github.com/soramikan/lnako/pull/92)）、LLVMツールチェーンキャッシュ更新（[#88](https://github.com/soramikan/lnako/pull/88)）、クリティカルパス平準化（[#91](https://github.com/soramikan/lnako/pull/91)）を実施し、CI実行時間を大幅に短縮しました。

## インストール

### macOS：Homebrewでインストール（推奨）

```sh
brew tap soramikan/tap
brew install lnako
lnako --version
```

インストール後、`lnako run` ですぐにプログラムを実行できます。ネイティブ実行ファイルを作る場合は、初回に `lnako toolchain install` を実行してください。

### ファイルをダウンロードして使う

お使いのOS・CPUに合うファイルを、次の表からダウンロードしてください。

- **standard**：プログラムの実行・構文チェックを始めたい方向けの軽量版です。後から `lnako toolchain install` でコンパイルに必要なLLVM/LLDを追加できます。
- **full**：LLVM/LLDを同梱しています。追加のダウンロードなしですぐにネイティブ実行ファイルの作成を行いたい方はこちらを選んでください。

| OS・CPU | standard | full（LLVM/LLD同梱） |
| --- | --- | --- |
| macOS・Apple Silicon（arm64） | [lnako-0.2.1-macos-arm64.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.2.1/lnako-0.2.1-macos-arm64.tar.gz) | [lnako-0.2.1-macos-arm64-full.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.2.1/lnako-0.2.1-macos-arm64-full.tar.gz) |
| Linux・x86_64（GNU） | [lnako-0.2.1-linux-x64.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.2.1/lnako-0.2.1-linux-x64.tar.gz) | [lnako-0.2.1-linux-x64-full.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.2.1/lnako-0.2.1-linux-x64-full.tar.gz) |
| Windows・x86_64 | [lnako-0.2.1-windows-x64.zip](https://github.com/soramikan/lnako/releases/download/v0.2.1/lnako-0.2.1-windows-x64.zip) | [lnako-0.2.1-windows-x64-full.zip](https://github.com/soramikan/lnako/releases/download/v0.2.1/lnako-0.2.1-windows-x64-full.zip) |

展開後はフォルダー構成を保ったまま、`bin` フォルダーをPATHに追加してください。macOS版はDeveloper IDによるコード署名・Appleの公証に対応しています。

## はじめての実行

UTF-8で `hello.nako3` を作成します。

```nako3
「こんにちは、世界！」と表示する。
```

```sh
lnako check hello.nako3          # 構文・意味チェック
lnako run hello.nako3            # スクリプトとして直接実行
```

ネイティブ実行ファイルを作る場合：

```sh
# standard版・Homebrewでは初回のみ必要（full版では不要）
lnako toolchain install
lnako build hello.nako3 -o hello -O2
./hello
```

Windowsでは出力名を `hello.exe` にして、`.\hello.exe` で実行してください。詳しい導入手順は[使い始める](../GETTING_STARTED.md)をご覧ください。

## その他の添付ファイル

通常のインストールでは、上の表のアーカイブだけで始められます。

- `*.sha256` / `SHA256SUMS`：ダウンロードしたファイルのチェックサム確認用。
- `*.spdx.json`：同梱ソフトウェアの構成情報（SBOM）。
- `benchmark-*.md` / `benchmark-*.json`：各OSのベンチマーク結果。
- `Source code (zip / tar.gz)`：ソースからビルドする開発者向け。
