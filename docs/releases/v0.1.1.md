# lnako v0.1.1 リリースノート

日本語プログラミング言語なでしこ3のネイティブコンパイラ `lnako` バージョン **v0.1.1** のリリースです。
本バージョンでは、対話的な入力処理の改善、和文代入構文の拡充、および最新CIによるattestation snapshotの追跡・検証を行いました。

## 主な変更点（v0.1.0からの改善）

### 1. 対話型入力の改善
- **対話型ターミナル（TTY）での一行入力の安定化**：
  - 「尋ねる」命令において、対話型環境でユーザーの入力を1行ずつ確実に標準入力から読み取れるよう修正しました。
  - 改行コード（CRLF / LF）や複数行入力、パイプライン経由の入力に対しても安定して動作します。

### 2. 和文代入構文および構文解析の拡充
- **連文結果の和文代入**：
  - 「尋ねて...に代入」のように、連文の結果を和文助詞の代入構文で受け取れるよう改善しました。
- **「定める」構文への対応**：
  - 「Aを1に定める」構文に対応しました（「定める」において「を」を定義対象、「に」を代入値として解析）。
- **配列要素・プロパティへの代入**：
  - 配列要素やオブジェクトプロパティに対する和文代入の解析精度と実行時処理を向上させました。

### 3. 互換性証拠（attestation snapshot）の追跡・更新
- 最新のCI run（`34402208204`）が生成したattestation snapshotを追跡し、macOS arm64・Linux x86_64・Windows x86_64の3 OS環境すべてで標準cnako 527命令の網羅的検証（`verified: 527`）を実証・維持しています。
- 証拠文書の構造化マーカー対応を行い、継続的な検証状態の追跡を強化しました。

## インストール

### macOS：Homebrewでインストール（推奨）

```sh
brew tap soramikan/tap
brew install lnako
lnako --version
```

インストール後、`lnako run` ですぐにプログラムを実行できます。ネイティブ実行ファイルを作る場合は、初回に `lnako toolchain install` を実行してください。

### ファイルをダウンロードして使う

お使いのOS・CPUに合うファイルを、次の表からダウンロードしてください。

- **standard**：プログラムの実行・構文チェックを始めたい方向けの軽量版です。後から `lnako toolchain install` でコンパイルに必要なLLVM/LLDを追加できます。
- **full**：LLVM/LLDを同梱しています。追加のダウンロードなしですぐにネイティブ実行ファイルの作成を行いたい方はこちらを選んでください。

| OS・CPU | standard | full（LLVM/LLD同梱） |
| --- | --- | --- |
| macOS・Apple Silicon（arm64） | [lnako-0.1.1-macos-arm64.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.1.1/lnako-0.1.1-macos-arm64.tar.gz) | [lnako-0.1.1-macos-arm64-full.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.1.1/lnako-0.1.1-macos-arm64-full.tar.gz) |
| Linux・x86_64（GNU） | [lnako-0.1.1-linux-x64.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.1.1/lnako-0.1.1-linux-x64.tar.gz) | [lnako-0.1.1-linux-x64-full.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.1.1/lnako-0.1.1-linux-x64-full.tar.gz) |
| Windows・x86_64 | [lnako-0.1.1-windows-x64.zip](https://github.com/soramikan/lnako/releases/download/v0.1.1/lnako-0.1.1-windows-x64.zip) | [lnako-0.1.1-windows-x64-full.zip](https://github.com/soramikan/lnako/releases/download/v0.1.1/lnako-0.1.1-windows-x64-full.zip) |

展開後はフォルダー構成を保ったまま、`bin` フォルダーをPATHに追加してください。macOS版はDeveloper IDによるコード署名・Appleの公証に対応しています。

## はじめての実行

UTF-8で `hello.nako3` を作成します。

```nako3
「こんにちは」と表示する。
```

```sh
lnako check hello.nako3          # 構文・意味チェック
lnako run hello.nako3            # スクリプトとして直接実行
```

ネイティブ実行ファイルを作る場合：

```sh
# standard版・Homebrewでは初回のみ必要（full版では不要）
lnako toolchain install
lnako build hello.nako3 -o hello -O2
./hello
```

Windowsでは出力名を `hello.exe` にして、`.\hello.exe` で実行してください。詳しい導入手順は[はじめに](../GETTING_STARTED.md)をご覧ください。

## その他の添付ファイル

通常のインストールでは、上の表のアーカイブだけで始められます。

- `*.sha256` / `SHA256SUMS`：ダウンロードしたファイルのチェックサム確認用。
- `*.spdx.json`：同梱ソフトウェアの構成情報（SBOM）。
- `benchmark-*.md` / `benchmark-*.json`：各OSのベンチマーク結果。
- `Source code (zip / tar.gz)`：ソースからビルドする開発者向け。
