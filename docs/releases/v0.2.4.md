# lnako v0.2.4 リリースノート

日本語プログラミング言語なでしこ3のネイティブコンパイラ `lnako` バージョン **v0.2.4** のリリースです。
本バージョンでは、パッケージ管理システムにおけるnpm依存解決および `nako.lock` への `npmInstances` 記録に対応し、ビルド基盤をZig 0.17.0へ移行しました。

## 主な変更点（v0.2.3からの改善）

### 1. パッケージ管理システムでのnpm依存解決と `npmInstances` 生成

- **npm依存グラフの解決と `nako.lock` 記録**：
  - ルートマニフェスト（`nako.toml`）および有効ななでしこパッケージ（`pkg`）が宣言する `source = "npm"` の依存を、ローカルのfixtureカタログまたはnpmレジストリのpackumentから解決し、`nako.lock` の `npmInstances` へ出力するようにしました（[#53](https://github.com/soramikan/lnako/issues/53), [#214](https://github.com/soramikan/lnako/pull/214)）。
  - これまで暫定措置として入っていたnpm依存に対するロック拒否ガード（`rejectNpmDeps`）を撤去し、`lnako lock`・`lnako add --npm`・`lnako update`・`lnako sync` の各経路から一貫してnpm依存を解決できます。

- **tarballの整合性検証・キャッシュ格納と `prefer_locked` 再利用**：
  - 取得したnpm tarballに対して `sha512-`（SRI形式）のハッシュ検証を行い、検証済みのアーカイブをパッケージキャッシュへ保存します。
  - 既存のロックファイルを優先する `prefer_locked` モードでは、要求されたSemVer範囲を満たす既存の `npmInstances` を再利用し、不要な再解決やバージョン変動を防ぎます。

- **peerDependenciesの充足検査とコンテキスト診断**：
  - 通常の `dependencies`・`optionalDependencies` に加えて `peerDependencies`（`peerDependenciesMeta` の任意指定を含む）を辿り、要求範囲の交差による自動解決や、解決不能・欠落時の構造化診断（`E017`）を実装しました。
  - ブラウザ専用条件など、現在の実行ターゲットと矛盾するパッケージ要求に対してはコンテキスト不整合診断（`E018`）を報告します。

### 2. Zig 0.17.0ツールチェーンへの移行とビルド基盤の改善

- **Zig 0.17.0への対応と依存ライブラリの更新**：
  - コンパイラおよびランタイムの基準ツールチェーンをZig `0.17.0` へ移行し、依存解決ライブラリ `zig-pubgrub` を `v0.1.2` へ更新しました（[#213](https://github.com/soramikan/lnako/pull/213)）。
  - Homebrew公式のZig 0.17環境でもそのままソースビルドとBottle生成が行えるようになりました。

- **Windows環境におけるファイルI/Oの安定化**：
  - Zig 0.17の標準I/O仕様変更に伴い、Windows環境でパスダイジェスト算出やパッケージキャッシュ読み込みを行う際に発生していた非ブロッキングI/O由来のハングを解消しました。

## インストール

### macOS：Homebrewでインストール（推奨）

```sh
brew tap soramikan/tap
brew install lnako
lnako --version
```

インストール後、`lnako run` ですぐにプログラムを実行できます。ネイティブ実行ファイルを作る場合は、初回に `lnako toolchain install` を実行してください。

### ファイルをダウンロードして使う

お使いのOS・CPUに合うファイルを、次の表からダウンロードしてください。

- **standard**：プログラムの実行・構文チェックを始めたい方向けの軽量版です。後から `lnako toolchain install` でコンパイルに必要なLLVM/LLDを追加できます。
- **full**：LLVM/LLDを同梱しています。追加のダウンロードなしですぐにネイティブ実行ファイルを作成したい方はこちらを選んでください。

| OS・CPU | standard | full（LLVM/LLD同梱） |
| --- | --- | --- |
| macOS・Apple Silicon（arm64） | [lnako-0.2.4-macos-arm64.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.2.4/lnako-0.2.4-macos-arm64.tar.gz) | [lnako-0.2.4-macos-arm64-full.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.2.4/lnako-0.2.4-macos-arm64-full.tar.gz) |
| Linux・x86_64（GNU） | [lnako-0.2.4-linux-x64.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.2.4/lnako-0.2.4-linux-x64.tar.gz) | [lnako-0.2.4-linux-x64-full.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.2.4/lnako-0.2.4-linux-x64-full.tar.gz) |
| Windows・x86_64 | [lnako-0.2.4-windows-x64.zip](https://github.com/soramikan/lnako/releases/download/v0.2.4/lnako-0.2.4-windows-x64.zip) | [lnako-0.2.4-windows-x64-full.zip](https://github.com/soramikan/lnako/releases/download/v0.2.4/lnako-0.2.4-windows-x64-full.zip) |

展開後はフォルダー構成を保ったまま、`bin` フォルダーをPATHに追加してください。macOS版はDeveloper IDによるコード署名・Appleの公証に対応しています。

## はじめての実行

UTF-8で `hello.nako3` を作成します。

```nako3
「こんにちは、世界！」と表示する。
```

```sh
lnako check hello.nako3          # 構文・意味チェック
lnako run hello.nako3            # スクリプトとして直接実行
```

ネイティブ実行ファイルを作る場合：

```sh
# standard版・Homebrewでは初回のみ必要（full版では不要）
lnako toolchain install
lnako build hello.nako3 -o hello -O2
./hello
```

Windowsでは出力名を `hello.exe` にして、`.\hello.exe` で実行してください。詳しい導入手順は[使い始める](../GETTING_STARTED.md)をご覧ください。

## その他の添付ファイル

通常のインストールでは、上の表のアーカイブだけで始められます。

- `*.sha256` / `SHA256SUMS`：ダウンロードしたファイルのチェックサム確認用。
- `*.spdx.json`：同梱ソフトウェアの構成情報（SBOM）。
- `Source code (zip / tar.gz)`：ソースからビルドする開発者向け。
