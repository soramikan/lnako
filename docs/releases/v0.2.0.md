# lnako v0.2.0 リリースノート

日本語プログラミング言語なでしこ3のネイティブコンパイラ `lnako` バージョン **v0.2.0** のリリースです。
本バージョンは、なでしこ3向け共通パッケージシステムの基盤実装、高効率な低レイヤーAPI群の追加、DNCL完全互換、互換性証拠管理の刷新、および利用者向けドキュメントの全面刷新を含む大型アップデートです。

## 主な新機能と変更点

### 1. なでしこ3向けパッケージシステム基盤の実装
- **仕様案の策定とスキーマ適合性検証**：
  - なでしこ3処理系共通で利用できるパッケージシステム仕様案（`nako.toml`）を策定しました（[仕様案ドキュメント](../package-system/SPECIFICATION.md)）。
- **Zig製PubGrub依存解決器**：
  - 高度な依存関係解決アルゴリズム「PubGrub」をZigでネイティブ実装し、決定論的なバージョン解決と、競合発生時のわかりやすい理由説明機能を提供します。
- **マニフェスト解析と条件付き依存**：
  - TOML形式のマニフェスト、セマンティックバージョニング（SemVer）、環境マーカー、フィーチャー（features）の解析エンジンを実装しました。
  - 共通 `.nako3` の優先読み込み、実行時条件判定、`engines` による処理系バージョン制約に対応しました。

### 2. 低レイヤーAPI・ストリームI/O・ファイルシステムの拡充
- **G0 Foundationと構造化エラー**：
  - 外部システム連携や高速I/Oの基盤となる低レイヤー命令カタログと、構造化エラーハンドリング機構を導入しました。
- **raw標準入出力と共有stdin source**：
  - バッファを介さないraw標準入出力命令（`標準入力読`、`標準出力書`、`標準エラー書` 等）を実装し、パイプライン連携を強化しました。
- **逐次ハッシュAPI**：
  - 大規模データを省メモリで処理できるインクリメンタルハッシュ命令（ハッシュ開始/追加/完了/破棄）を追加しました。
- **低層ファイルシステムAPI**：
  - ファイル詳細情報取得（`stat` / `lstat`）、リンク作成（ハードリンク / シンボリックリンク）、`ファイル名変更`（rename）、`ファイル削除`（unlink）などの低水準ファイル操作命令群を追加しました。

### 3. DNCL（共通テスト手順記述標準言語）の完全互換と直接コンパイル
- 大学入学共通テスト「情報I」で使用されるDNCL手順記述言語の完全互換を実現し、直接コンパイルおよび構造例外の責務分割を行いました。

### 4. 互換性証拠管理の刷新
- 互換性証拠をcanonical形へと分離し、各コミットに依存しない走査型のattestation snapshot解決アーキテクチャへ移行しました。

### 5. ドキュメント類の利用者向け全面刷新
- はじめてlnakoを利用する方に向けて、README、使い始めガイド（`GETTING_STARTED.md`）、配布仕様（`RELEASE.md`）、互換性ガイドを親しみやすくわかりやすい構成に全面的に改訂しました。

## インストール

### macOS：Homebrewでインストール（推奨）

```sh
brew tap soramikan/tap
brew install lnako
lnako --version
```

インストール後、`lnako run` ですぐにプログラムを実行できます。ネイティブ実行ファイルを作る場合は、初回に `lnako toolchain install` を実行してください。

### ファイルをダウンロードして使う

お使いのOS・CPUに合うファイルを、次の表からダウンロードしてください。

- **standard**：プログラムの実行・構文チェックを始めたい方向けの軽量版です。後から `lnako toolchain install` でコンパイルに必要なLLVM/LLDを追加できます。
- **full**：LLVM/LLDを同梱しています。追加のダウンロードなしですぐにネイティブ実行ファイルの作成を行いたい方はこちらを選んでください。

| OS・CPU | standard | full（LLVM/LLD同梱） |
| --- | --- | --- |
| macOS・Apple Silicon（arm64） | [lnako-0.2.0-macos-arm64.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.2.0/lnako-0.2.0-macos-arm64.tar.gz) | [lnako-0.2.0-macos-arm64-full.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.2.0/lnako-0.2.0-macos-arm64-full.tar.gz) |
| Linux・x86_64（GNU） | [lnako-0.2.0-linux-x64.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.2.0/lnako-0.2.0-linux-x64.tar.gz) | [lnako-0.2.0-linux-x64-full.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.2.0/lnako-0.2.0-linux-x64-full.tar.gz) |
| Windows・x86_64 | [lnako-0.2.0-windows-x64.zip](https://github.com/soramikan/lnako/releases/download/v0.2.0/lnako-0.2.0-windows-x64.zip) | [lnako-0.2.0-windows-x64-full.zip](https://github.com/soramikan/lnako/releases/download/v0.2.0/lnako-0.2.0-windows-x64-full.zip) |

展開後はフォルダー構成を保ったまま、`bin` フォルダーをPATHに追加してください。macOS版はDeveloper IDによるコード署名・Appleの公証に対応しています。

## はじめての実行

UTF-8で `hello.nako3` を作成します。

```nako3
「こんにちは、世界！」と表示する。
```

```sh
lnako check hello.nako3          # 構文・意味チェック
lnako run hello.nako3            # スクリプトとして直接実行
```

ネイティブ実行ファイルを作る場合：

```sh
# standard版・Homebrewでは初回のみ必要（full版では不要）
lnako toolchain install
lnako build hello.nako3 -o hello -O2
./hello
```

Windowsでは出力名を `hello.exe` にして、`.\hello.exe` で実行してください。詳しい導入手順は[使い始める](../GETTING_STARTED.md)をご覧ください。

## その他の添付ファイル

通常のインストールでは、上の表のアーカイブだけで始められます。

- `*.sha256` / `SHA256SUMS`：ダウンロードしたファイルのチェックサム確認用。
- `*.spdx.json`：同梱ソフトウェアの構成情報（SBOM）。
- `benchmark-*.md` / `benchmark-*.json`：各OSのベンチマーク結果。
- `Source code (zip / tar.gz)`：ソースからビルドする開発者向け。
