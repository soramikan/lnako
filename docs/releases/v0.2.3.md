# lnako v0.2.3 リリースノート

日本語プログラミング言語なでしこ3のネイティブコンパイラ `lnako` バージョン **v0.2.3** のリリースです。
本バージョンでは、プロジェクト依存管理CLIおよび `run` / `test` / `build` 実行前の自動環境準備、同期済みパッケージの `取り込む`（import）解決、低レイヤーAPIカタログ全63命令の実装完遂（位置指定I/O・CoWファイルクローン・スパースシーク・領域確保・Windowsハードリンク）、および関数内変数・クロージャ束縛の公式互換性修正を実施しました。

## 主な変更点（v0.2.2からの改善）

### 1. パッケージ管理CLIとパッケージimportの実装

- **依存管理CLIと実行前の自動環境準備**：
  - プロジェクト初期化・依存編集・検査を行うCLIサブコマンド（`init`、`init --lib`、`add`、`remove`、`lock`、`update`、`tree`、`why`、`check`、`cache dir|clean`）を実装しました（[#49](https://github.com/soramikan/lnako/issues/49), [#176](https://github.com/soramikan/lnako/pull/176)）。
  - プロジェクト内で `lnako run`、`lnako test`、`lnako build` を実行する際、`nako.lock` の解決と `.nako` 環境の同期を自動で準備するようにしました。`--locked`、`--offline`、`--no-sync`、`--profile`、`--features`、`--registry` などの制御フラグにも対応しています。
  - 複数のプロセスが同時にマニフェストやロックファイルを操作しても競合しないよう `.nako/edit.lock` による直列化を導入し、不変path依存のツリーハッシュ検証や循環依存（cycle）の検出を強化しました。

- **同期済みパッケージの `取り込む`（import）解決**：
  - `「パッケージ:名」を取り込む` および `「pkg:名/サブパス」を取り込む` によるパッケージモジュールの読み込みと名前空間解決を、インタープリターとAOTコンパイラの双方で実装しました（[#50](https://github.com/soramikan/lnako/issues/50), [#196](https://github.com/soramikan/lnako/pull/196)）。
  - `nako.lock`（v2）にプロファイル別のルート依存エッジを記録し、選択したプロファイルで許可された依存エイリアスと公開エクスポート境界のみを解決するようにしました。
  - パッケージ経由で読み込んだネイティブプラグイン命令を `{エイリアス}__{命令}` の名前空間付きで登録し、異なるパッケージ間で同名の命令があっても衝突しないようにしました。
  - プロジェクト境界を越える親ディレクトリの `.nako` 参照や、パッケージルート外への相対・絶対パス脱出、信頼できない所有者のファイル読み取りを拒否する境界検査を追加しました。

### 2. 低レイヤーAPIカタログ全63命令の実装完了

- **ストリーム位置指定I/O（4命令）**：
  - ファイルハンドルのシーク位置を変更・取得する `ファイル位置変更`（`lseek` 相当）・`ファイル位置取得`、および現在位置を変えずに指定オフセットで読み書きする `ファイル位置指定読込`（`pread` 相当）・`ファイル位置指定書込`（`pwrite` 相当）をインタープリターとAOTの双方で実装しました（[#27](https://github.com/soramikan/lnako/issues/27), [#207](https://github.com/soramikan/lnako/pull/207)）。
  - Windows環境でも `pread` / `pwrite` 実行後にファイルハンドルの現在位置が変化しないよう位置の保存・復元を行い、追記モード（`"a"` / `"a+"`）のハンドルに対する `ファイル位置指定書込` を `EINVAL` で拒否するように契約を統一しました。

- **ファイルシステム情報・CoWクローン・スパースファイル・事前領域確保（5命令）**：
  - `ファイルシステム情報取得`（`statvfs` / `statfs` 相当）、Copy-on-Writeで高速に複製する `ファイルクローン`（`clonefile` / `FICLONE` 相当）、スパースファイルのデータ領域・空洞領域を探す `ファイルデータ領域検索`（`SEEK_DATA`）・`ファイル空洞領域検索`（`SEEK_HOLE`）、および物理領域を事前確保する `ファイル領域確保`（`fallocate` / `F_PREALLOCATE` 相当）を実装しました（[#36](https://github.com/soramikan/lnako/issues/36), [#181](https://github.com/soramikan/lnako/pull/181)）。
  - `ファイルクローン` では一時ファイルへの複製と原子的リネーム（`RENAME_EXCL` / `RENAME_NOREPLACE`）を組み合わせることで、失敗時に既存のファイルを破損させず、TOCTOU競合やFIFOブロックも防ぐ構造にしました。

- **Windows（NTFS）でのハードリンク作成対応**：
  - Win32 APIの `CreateHardLinkW` を用いて、WindowsのNTFS上でも `ハードリンク作成` が動作するようにしました（[#78](https://github.com/soramikan/lnako/issues/78), [#208](https://github.com/soramikan/lnako/pull/208)）。
  - これにより、`docs/low-level-api/catalog.json` に定義された低レイヤーAPI全63命令の実装が完了しました（63/63命令）。

### 3. なでしこ3言語互換性とツールチェーンの改善

- **関数内変数・無名関数クロージャ束縛の公式互換化**：
  - 無名関数や入れ子関数をまたいで外側スコープの変数・仮引数を参照・代入する際の解決規則を公式なでしこ3（v3.7.24）と一致させ、読み取り経路と書き込み経路で異なる変数を参照してしまう不具合を修正しました（[#194](https://github.com/soramikan/lnako/pull/194)）。

- **ツールチェーン導入の高速化と進捗表示**：
  - `lnako toolchain install` 実行時に進行状況を表示するようにし、LLVMツールチェーンの複製処理を高速化しました（[#193](https://github.com/soramikan/lnako/pull/193)）。

- **リリース公開とHomebrew tap連携の自動化**：
  - GitHub Release公開時に `docs/releases/vX.Y.Z.md` をリリース本文へ自動適用し、`soramikan/homebrew-tap` のFormula・Bottle更新ワークフローを自動起動するように改善しました。

## インストール

### macOS：Homebrewでインストール（推奨）

```sh
brew tap soramikan/tap
brew install lnako
lnako --version
```

インストール後、`lnako run` ですぐにプログラムを実行できます。ネイティブ実行ファイルを作る場合は、初回に `lnako toolchain install` を実行してください。

### ファイルをダウンロードして使う

お使いのOS・CPUに合うファイルを、次の表からダウンロードしてください。

- **standard**：プログラムの実行・構文チェックを始めたい方向けの軽量版です。後から `lnako toolchain install` でコンパイルに必要なLLVM/LLDを追加できます。
- **full**：LLVM/LLDを同梱しています。追加のダウンロードなしですぐにネイティブ実行ファイルを作成したい方はこちらを選んでください。

| OS・CPU | standard | full（LLVM/LLD同梱） |
| --- | --- | --- |
| macOS・Apple Silicon（arm64） | [lnako-0.2.3-macos-arm64.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.2.3/lnako-0.2.3-macos-arm64.tar.gz) | [lnako-0.2.3-macos-arm64-full.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.2.3/lnako-0.2.3-macos-arm64-full.tar.gz) |
| Linux・x86_64（GNU） | [lnako-0.2.3-linux-x64.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.2.3/lnako-0.2.3-linux-x64.tar.gz) | [lnako-0.2.3-linux-x64-full.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.2.3/lnako-0.2.3-linux-x64-full.tar.gz) |
| Windows・x86_64 | [lnako-0.2.3-windows-x64.zip](https://github.com/soramikan/lnako/releases/download/v0.2.3/lnako-0.2.3-windows-x64.zip) | [lnako-0.2.3-windows-x64-full.zip](https://github.com/soramikan/lnako/releases/download/v0.2.3/lnako-0.2.3-windows-x64-full.zip) |

展開後はフォルダー構成を保ったまま、`bin` フォルダーをPATHに追加してください。macOS版はDeveloper IDによるコード署名・Appleの公証に対応しています。

## はじめての実行

UTF-8で `hello.nako3` を作成します。

```nako3
「こんにちは、世界！」と表示する。
```

```sh
lnako check hello.nako3          # 構文・意味チェック
lnako run hello.nako3            # スクリプトとして直接実行
```

ネイティブ実行ファイルを作る場合：

```sh
# standard版・Homebrewでは初回のみ必要（full版では不要）
lnako toolchain install
lnako build hello.nako3 -o hello -O2
./hello
```

Windowsでは出力名を `hello.exe` にして、`.\hello.exe` で実行してください。詳しい導入手順は[使い始める](../GETTING_STARTED.md)をご覧ください。

## その他の添付ファイル

通常のインストールでは、上の表のアーカイブだけで始められます。

- `*.sha256` / `SHA256SUMS`：ダウンロードしたファイルのチェックサム確認用。
- `*.spdx.json`：同梱ソフトウェアの構成情報（SBOM）。
- `benchmark-*.md` / `benchmark-*.json`：各OSのベンチマーク結果。
- `Source code (zip / tar.gz)`：ソースからビルドする開発者向け。
