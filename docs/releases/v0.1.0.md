# lnako v0.1.0 リリースノート

なでしこ3のプログラムを実行し、ネイティブ実行ファイルへコンパイルできる `lnako` の初回リリースです。なでしこ3 **v3.7.24** を互換基準としています。

## 主な対応範囲

- なでしこ3ソースのインタープリター実行（`run`）、構文チェック（`check`）、LLVMを使ったネイティブ実行ファイルの生成（`build`）に対応。
- 標準cnako命令 **527件** のうち、**523件をネイティブ実装**、残る **4件を明示的な `--compat-js` モード** で提供。通常モードではJavaScriptランタイムを使用せず、高速かつ軽量に動作。
- macOS arm64、Linux x86_64 GNU、Windows x86_64 MSVCの3 OSを正式環境とし、網羅的な互換テスト（verified: 527）を達成。
- ネイティブプラグイン（`.dylib` / `.so` / `.dll`）の動的読み込みに対応。

## インストール

### macOS：Homebrewでインストール

```sh
brew tap soramikan/tap
brew install lnako
lnako --version
```

インストール後、`lnako run` ですぐにプログラムを実行できます。ネイティブ実行ファイルを作る場合は、初回に `lnako toolchain install` を実行してください。

### ファイルをダウンロードして使う

お使いのOS・CPUに合うファイルを、次の表からダウンロードしてください。

- **standard**：プログラムの実行・構文チェックを始めたい方向けの軽量版です。後から `lnako toolchain install` でコンパイルに必要なLLVM/LLDを追加できます。
- **full**：LLVM/LLDを同梱しています。追加のダウンロードなしですぐにネイティブ実行ファイルの作成を行いたい方はこちらを選んでください。

| OS・CPU | standard | full（LLVM/LLD同梱） |
| --- | --- | --- |
| macOS・Apple Silicon（arm64） | [lnako-0.1.0-macos-arm64.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.1.0/lnako-0.1.0-macos-arm64.tar.gz) | [lnako-0.1.0-macos-arm64-full.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.1.0/lnako-0.1.0-macos-arm64-full.tar.gz) |
| Linux・x86_64（GNU） | [lnako-0.1.0-linux-x64.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.1.0/lnako-0.1.0-linux-x64.tar.gz) | [lnako-0.1.0-linux-x64-full.tar.gz](https://github.com/soramikan/lnako/releases/download/v0.1.0/lnako-0.1.0-linux-x64-full.tar.gz) |
| Windows・x86_64 | [lnako-0.1.0-windows-x64.zip](https://github.com/soramikan/lnako/releases/download/v0.1.0/lnako-0.1.0-windows-x64.zip) | [lnako-0.1.0-windows-x64-full.zip](https://github.com/soramikan/lnako/releases/download/v0.1.0/lnako-0.1.0-windows-x64-full.zip) |

展開後はフォルダー構成を保ったまま、`bin` フォルダーをPATHに追加してください。macOS版はDeveloper IDによるコード署名・Appleの公証に対応しています。

## はじめての実行

UTF-8で `hello.nako3` を作成します。

```nako3
「こんにちは」と表示する。
```

```sh
lnako check hello.nako3          # 構文・意味チェック
lnako run hello.nako3            # 直接実行
```

ネイティブ実行ファイルを作る場合：

```sh
# standard版・Homebrewでは初回のみ必要（full版では不要）
lnako toolchain install
lnako build hello.nako3 -o hello -O2
./hello
```

Windowsでは出力名を `hello.exe` にして、`.\hello.exe` で実行してください。

## その他の添付ファイル

- `*.sha256` / `SHA256SUMS`：ダウンロードしたファイルのチェックサム確認用。
- `*.spdx.json`：同梱ソフトウェアの構成情報（SBOM）。
- `benchmark-*.md` / `benchmark-*.json`：各OSのベンチマーク結果。
- `Source code (zip / tar.gz)`：ソースからビルドする開発者向け。
